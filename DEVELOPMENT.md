# Продолжение разработки StudyFlow

## Получение актуального проекта

```sh
git clone https://github.com/dileeeekk/StudyFlow.git
cd StudyFlow
git switch main
```

Если клон уже есть, сначала сохраните свою работу коммитом и выполните `git pull --ff-only origin main`.
В Android Studio откройте `StudyFlow/android`. Подробности установки SDK, локального Django и адреса API — в README.md.

## Текущая реализация

- Kotlin + XML/Android Views, без Compose.
- `HomeActivity` подключает авторизованный профиль и `PlannerUi`.
- `PlannerUi.kt` переключает вкладки и отображает данные; `view_tasks.xml` и `view_schedule.xml` задают новые экраны. Шапка главной страницы отдельная, её не нужно переносить во вкладки.
- `PlannerForm.kt` содержит формы создания и редактирования, выбор даты/времени, проверки полей, подтверждение удаления.
- `PlannerViewModel.kt` выполняет запросы и хранит состояние. `AuthRepository.kt` добавляет JWT и обновляет токены.
- Django `planner` хранит Task, Lesson, Note, FocusSession, StudyGoal, связывая их с аккаунтом. API уже развёрнут на PythonAnywhere. Клиентские изменения Schedule/Tasks не требуют новых миграций.
- При первом запуске своего Django выполните все миграции. Облачная база и пользовательские аккаунты в GitHub не входят.

## Что проверить после изменений

1. Новый аккаунт: главная, Schedule и Tasks пустые, точка колокольчика отсутствует.
2. Создание задачи: карточка появляется на главной и Tasks, данные сохраняются после перезапуска.
3. Tasks: фильтры, сортировки, выполнение и отмена выполнения, редактирование и удаление.
4. Schedule: предыдущая/следующая неделя, выбор дня, создание занятия на выбранную дату, время окончания позже начала.
5. Вход, выход, повторный вход, истечение access token, ошибка сети без потери введённой формы.
6. `gradlew.bat assembleDebug` в `android`; `python manage.py test accounts planner config` в окружении backend.

## Границы текущего этапа

Занятия разовые, время учёбы вводится вручную. Нет офлайн-синхронизации, push, таймера, восстановления пароля, подтверждения email. Profile — диалог аккаунта. Обновление индикаторов времени происходит при перерисовке экрана; автоматический таймер обновления можно добавить следующим этапом.

Исторические папки с подготовительными скриптами и APK — справочные материалы, а не исходники для сборки. Не запускайте их для наложения старых версий. Продолжайте работу непосредственно в `android` и `studyflow-backend`.

Для управления существующим хостингом нужен отдельный доступ владельца PythonAnywhere. Пароли, JWT, базы данных, приватные ключи и local.properties не коммитить. Друг может независимо разрабатывать и тестировать проект на собственном локальном backend.
