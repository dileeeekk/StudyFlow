# StudyFlow на настоящем телефоне

Причина ошибки «Cannot reach the server»: Django был остановлен, а приложение использовало адрес `10.0.2.2`, предназначенный для эмулятора.

Исправлено:

- Сервер запущен на компьютере.
- Настроен канал USB командой `adb reverse tcp:8000 tcp:8000`.
- В `C:\Users\admin\AndroidStudioProjects\StudyFlowApp\gradle.properties` добавлено `STUDYFLOW_API_URL=http://127.0.0.1:8000/api/`.
- Приложение пересобрано и установлено поверх существующего; база пользователей не удалялась.

## После переподключения USB или перезапуска компьютера

Подключи телефон по USB, разреши USB-отладку, открой Terminal в Android Studio и выполни:

```powershell
& 'C:\Users\admin\OneDrive\Documents\ChatGPT\Приложение StudyFlow\studyflow-backend\connect-phone.ps1'
```

Скрипт при необходимости запустит сервер и заново настроит USB-соединение. Если подключено несколько устройств, укажи нужное через параметр `-DeviceSerial SERIAL`; список доступен командой `adb devices`.

Если PowerShell запрещает запуск скриптов, можно выполнить обычные команды без изменения системной политики:

В первом терминале:

```powershell
Set-Location -LiteralPath 'C:\Users\admin\OneDrive\Documents\ChatGPT\Приложение StudyFlow\studyflow-backend'
& '.\.venv\Scripts\python.exe' manage.py runserver 127.0.0.1:8000
```

Во втором терминале, если подключён один телефон:

```powershell
& 'C:\Users\admin\AppData\Local\Android\Sdk\platform-tools\adb.exe' reverse tcp:8000 tcp:8000
```

Если сервер уже работает, повторно запускать его не нужно. После изменения настроек Gradle в Android Studio нажми **Sync Now**, если появилась синяя полоса, затем **Run ▶**.

## Как это работает

Телефон обращается к `127.0.0.1:8000`, а USB-перенаправление передаёт запрос на сервер компьютера. Поэтому для этой локальной версии нужны включённый компьютер, работающий Django и подключённый USB. Обычное подключение телефона к интернету само по себе не делает локальный сервер доступным.

Для работы приложения без компьютера и USB следующим отдельным этапом нужно разместить Django на хостинге с HTTPS и указать его адрес в приложении.

Этот же скрипт можно использовать с одним подключённым эмулятором. Если хочется вернуться к прямому адресу эмулятора `10.0.2.2`, удали строку `STUDYFLOW_API_URL` из `gradle.properties`, синхронизируй и пересобери приложение.
